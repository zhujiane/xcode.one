- 移除 FFmpeg 路径配置，自动复用 XCODE.ONE 内置 FFmpeg；新版本包可本地安装，保留 1.0.0 发布 ZIP 不覆盖。

## 2026-10-08 视频尾帧节点

- 新增 `xcode.video-last-frame@1.0.0` 代码插件和可本地安装 ZIP：输入一个视频，输出原尺寸 PNG 尾帧，自动入素材库，可连接后续图片节点。
- 优先复用客户端内置 FFmpeg，支持系统 PATH 与高级设置中的自定义路径；完整解码至最后一帧，保留黑帧和旋转信息，支持取消与临时文件清理。
- 提供源码、可重复构建脚本、安装说明和小范围实际视频验证，不运行完整 Playwright E2E。
