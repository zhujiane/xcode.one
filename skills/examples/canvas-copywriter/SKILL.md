# Canvas copywriter

1. Read the topic and the target node (`image` or `video`).
2. Write one concrete visual brief: subject, setting, light, style.
3. Keep model-specific jargon out. Leave `modelId` null so the app uses the type default.
4. Do not invent asset IDs or run history.
